# Creative Toolkit

REACT TASKS

1. Build a Weather Dashboard with city search, temperature, humidity and wind information.

2. Create an Image Gallery with Search, Category Filter and Preview Modal.

3. Build a Drag-and-Drop Kanban Board with Todo, In Progress, Review and Done columns.

4. Create a Password Generator with options for length, numbers, symbols and uppercase/lowercase characters.

5. Build a Countdown Timer with Start, Pause and Reset functionality.

6. Create a reusable Dropdown component with Search and Clear functionality.

7. Build a File Upload component with file type, file size validation, preview and remove functionality.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://react-palette-toolkit.lovable.app
